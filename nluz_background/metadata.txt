about=Displays Taiwan NLMA draft functional zone maps for 22 counties and cities, with ministry-review and public-exhibition stages. Images update after main-canvas pan or zoom; website sessions older than 30 minutes renew only when a new image is needed. Includes connection warnings, manual reconnection and project restoration.
    Taiwan only. Internet access is required. No additional Python packages are required beyond QGIS. The service uses the public NLUZ website session and proxy; successful access does not establish a stable public API or permission for continued third-party use. This is an independently developed tool, not an official NLMA product. Maps are drafts, not legally approved or promulgated results.
    Tokens and cookies remain in memory. Georeferenced image snapshots are stored in the local QGIS profile; they are not embedded in the QGZ. Custom QGIS proxy/authentication settings are not integrated. Layouts, atlases and secondary map views do not trigger new imagery.
    The maintainer reported successful operation of the code used in 1.0.0 on Windows with QGIS 4.2.3. Version 1.0.1 renames one local variable and adds bilingual descriptions. This revision has not been separately tested in a live QGIS session. Other declared versions and operating systems have not been separately validated.
    This plugin was generated using Codex.
    支援臺灣 22 縣市的國土功能分區草案圖，可選擇「報部審議階段」或「公開展覽階段」。主畫布平移、縮放後自動更新影像；Token 使用超過 30 分鐘後，等下次需要新影像時才更新，閒置時不定時請求。提供連線失效提示、手動重新連線及專案重開後恢復連線功能。
